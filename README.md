# FRIDA

FRIDA is a family of models for retrieval and structured decision-making.

| Project | What it does | Get started |
| --- | --- | --- |
| [FRIDA-Embeddings](embeddings/) | Encodes queries and documents as vectors for search. | [Original encoder](https://huggingface.co/ai-forever/FRIDA) · [V2 inference guide](embeddings/v2/inference/) |
| [FRIDA-Decisions](decisions/) | Classifies inputs, assigns scores, answers yes/no questions and ranks candidates. | [V1 quickstart](decisions/v1/#quickstart) · [Example notebooks](decisions/v1/examples/) |
